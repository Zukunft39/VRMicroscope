# PDF 公式修复记录（2026-09-20）

已覆盖正式版与匿名版目录中的中英文四份 PDF；原有四份 Word 文档的 SHA-256 校验值保持不变。

## 原因

原 PDF 的 Producer 为 LibreOffice 25.2.3.2。该转换链没有正确保留原生 Word 数学对象：行内绝对值分隔符显示成红色错误字符，SIM 三行公式被合并为一行并超出栏宽，部分数学字体也发生替换。

## 处理

使用 Microsoft Word 2021 原生数学排版重新导出，并保留数学文本和矢量线条。补嵌 Word 默认省略的 Times New Roman、Arial 字体，避免其他阅读器依赖本机替代字体；Cambria Math 已由 Word 嵌入。没有把公式转成截图，也没有改动公式内容。

`export_formal_pdf.ps1` 使用 Word 原生导出，并调用 `finalize_pdf_fonts.py` 检查及补嵌字体。后者依赖 PyMuPDF 与 fontTools，可使用项目现有 `.paper_tools`。这一路径输出普通 PDF，不宣称 PDF/A 合规。

- 放大核对了分段透明度、NA、衍射关系、SIM 三行式、混合频谱、可用动作集合及距离公式；分数、上下标、希腊字母和分隔符均可见，SIM 公式未越栏。
- 检查了行内数学符号及目标相关动作子集表达式；未发现替换字符、方框占位符、非黑色数学字形或数学文本越出页面正文边界。
- 字体补嵌前后，PDF 提取文本与页数完全一致。
- 匿名版正文及元数据检查未发现所列作者姓名、邮箱或作者单位标识。
- 导出脚本已用临时英文副本完成端到端验证。
